HTML Text Formatting

Bold text is created using the b tag.

Important text is created using the strong tag.

Italic text is created using the i tag.

Emphasized text is created using the em tag.

Underlined text is created using the u tag.

Highlighted text is created using the mark tag.

Small text is created using the small tag.

Deleted text is created using the del tag.

Inserted text is created using the ins tag.

CHALLENGE

H2O uses the sub tag.

X2 uses the sup tag.
